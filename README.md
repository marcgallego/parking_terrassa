# Còpia diària de les dades

Aquesta branca només conté els CSV d'ocupació dels pàrquings Saba de Terrassa,
copiats cada matinada des de https://parking.terrassa.workers.dev per una GitHub Action.
Estructura: `data/AAAA/AAAA-MM-DD.csv`, un per dia, i `data/AAAA/AAAA-MM.csv`, el mes sencer.
Esquema i llicència (CC BY 4.0): vegeu la branca `main`.
